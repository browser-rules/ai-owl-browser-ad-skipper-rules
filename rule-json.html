Blink Browser Automation Rules / Rule format

Rule JSON Format

The public subscription is a JSON document that Blink Browser can fetch, validate, and import into the local Ad Skipper rule manager.

Rule subscription
/rules/browser-ad-skipper-rules.json
Manifest metadata
/rules/manifest.json

What the JSON provides

The JSON contains rule subscription metadata and user-managed automation entries. Blink Browser decides whether a rule is valid, visible in the rule manager, and eligible for local execution after the user enables Ad Skipper.

Recommended import URL

Use the hosted URL instead of a downloaded file when possible. A stable URL gives users a repeatable source for future refreshes.
