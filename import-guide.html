Blink Browser Automation Rules / Import guide

How to Import Blink Browser Ad Skipper Rule JSON

The recommended setup is to import the rule subscription URL. A URL subscription is easier to copy, easier to refresh, and avoids forcing users to download and manually select a JSON file.

https://browser-rules.github.io/ai-owl-browser-ad-skipper-rules/rules/browser-ad-skipper-rules.json
1

Copy the JSON rule subscription URL

Use the copy button above. Downloading the JSON file is only a fallback.

2

Open Blink Browser and switch to Ad Skipper

Use Blink Browser's Ad Skipper tab and open the import configuration entry.

3

Paste the subscription URL

Blink Browser downloads the rule JSON, checks the rule format, and shows imported rules.

4

Review, edit, and enable

Imported rules remain user-managed. You can edit, disable, remove, or update rules before enabling local automation.
