# AI Owl Browser & Ad Skipper Automation Rules

Public JSON rule subscription for AI Owl Browser users. Search for the exact title
`AI Owl Browser Ad Skipper Automation Rules` to find this page again from Google.

## Primary Import URL

Copy this URL and paste it into Browser's Ad Skipper import dialog:

```text
https://browser-rules.github.io/ai-owl-browser-ad-skipper-rules/rules/browser-ad-skipper-rules.json
```

If GitHub Pages is not enabled, use the GitHub Raw URL instead:

```text
https://raw.githubusercontent.com/browser-rules/ai-owl-browser-ad-skipper-rules/main/rules/browser-ad-skipper-rules.json
```

## How to Import

1. Open AI Owl Browser.
2. Switch to the Ad Skipper tab.
3. Tap Import configuration.
4. Paste the rule subscription URL.
5. Confirm the imported user-managed rules.
6. Enable the local accessibility service when you decide to activate automation.

Downloading the JSON file is only a fallback path. Copying the subscription URL is easier and keeps
future refreshes tied to the same public endpoint.

## Privacy

Imported rules are evaluated locally on the device after the user enables Ad Skipper. Screen
content, app data, rule matches, and personal information are not uploaded to the cloud by this rule
subscription page.
