AI Owl Browser Automation Rules / Privacy

Privacy and Local-Only Automation

This site only publishes a public JSON rule subscription. Browser performs rule evaluation locally on the user's device after the user imports rules and enables Ad Skipper.

Local evaluation

Imported rules are checked on the device where Browser is installed.

No screen upload

Screen content, app data, rule matches, and personal information are not uploaded.

User control

Users decide whether to import, edit, enable, disable, update, or remove rules.

Permission boundary

Automatic actions require the local accessibility service and cannot run without it.
