Blink Browser Automation Rules / FAQ

FAQ

How do I import the Blink Browser Ad Skipper rule JSON?

Copy the subscription URL, open Blink Browser's Ad Skipper tab, paste the URL, and confirm.

Do I need to download the JSON file?

No. Copying the URL is the primary path. Downloading is only a manual fallback.

Can I edit imported rules?

Yes. Imported rules remain visible and editable in Blink Browser's rule management UI.

Why does automation require accessibility permission?

The local service needs accessibility permission before Blink Browser can perform supported actions.

Does this page activate Ad Skipper?

No. Blink Browser includes YouTube and YouTube Music rules. Import this JSON to add rules for other apps and ad platforms.
