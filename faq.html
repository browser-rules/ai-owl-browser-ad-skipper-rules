FAQ

How do I import the Browser Ad Skipper rule JSON?

Copy the subscription URL, open Browser's Ad Skipper tab, paste the URL, and confirm.

Do I need to download the JSON file?

No. Copying the URL is the primary path. Downloading is only a manual fallback.

Can I edit imported rules?

Yes. Imported rules remain visible and editable in Browser's rule management UI.

Why does automation require accessibility permission?

The local service needs accessibility permission before Browser can perform supported actions.

Does this page activate Ad Skipper?

No. This site only hosts JSON rules. Browser users must import and enable rules themselves.
